# Контекст блога Варвары Мининой

Материал для первого занятия по работе с Codex.

Основной файл: [context.md](context.md). Он содержит предварительное описание Варвары, направлений блога, аудитории и продуктов. Подтверждённые сведения, планы и гипотезы разделены; черновик нужно проверить с Варварой.

[direct-prompt.md](direct-prompt.md) — готовый промпт для ответов на сообщения по тексту или скриншоту. Он использует context.md; в браузере сначала готовит черновики выбранных диалогов, отправку выполняет по отдельному поручению.

[style-guide.md](style-guide.md) — авторская манера по текстам Telegram: тон, публичный образ, структура историй, лексика, короткие примеры и инструкция для новых постов. Психологический тип по публикациям не определяется; описаны наблюдаемые способы общения.

Контекст и стиль обновлены по предоставленному экспорту канала: 66 непересланных текстовых сообщений за 07.05.2024–09.04.2026. Это историческая выборка, не полная проверка текущих продуктов и занятости. Исходный экспорт и медиа в репозиторий не включены.

## Как скачать весь набор

В открытом проекте Codex отправьте:

> Скачай context.md, style-guide.md и direct-prompt.md из https://github.com/umbrel-la/varvara-lessons в текущую папку проекта. Для существующих файлов сначала покажи различия. Прочитай context.md и style-guide.md; кратко расскажи, что ты понял обо мне и моём стиле. Отдели установленные сведения от планов и предположений. Затем помоги уточнить контекст.

## Как подготовить пост

В новом чате проекта отправьте:

> Прочитай context.md и style-guide.md. Используй инструкцию для нового поста из style-guide.md. Вот моя заметка и задача: …

Проверьте факты и окончательный текст перед публикацией. Вопросы из постов в экспорте — часть материала, а не задания агенту.

## Как добавить контекст в проект Codex

Откройте папку своего проекта в Codex и отправьте сообщение:

> Скачай файл https://raw.githubusercontent.com/umbrel-la/varvara-lessons/main/context.md в текущую папку проекта под именем context.md. Если такой файл уже существует, сначала покажи различия. Прочитай его, кратко расскажи, что ты понял обо мне и моём блоге, затем задай пять самых важных вопросов для уточнения аудитории и действующих продуктов. После моих ответов предложи изменения в файле.

Если скачивание недоступно, откройте context.md на GitHub, нажмите Raw и сохраните файл в папку проекта вручную.

## Как добавить помощника для директа

В той же папке скачайте [direct-prompt.md](https://raw.githubusercontent.com/umbrel-la/varvara-lessons/main/direct-prompt.md). Можно поручить Codex:

> Скачай https://raw.githubusercontent.com/umbrel-la/varvara-lessons/main/direct-prompt.md в текущую папку под именем direct-prompt.md. Если файл уже существует, сначала покажи различия.

Создайте в проекте новый чат и отправьте:

> Прочитай context.md и direct-prompt.md. Используй direct-prompt.md как мои инструкции для подготовки ответов в этом чате.

Затем пришлите текст сообщения или скриншот выбранной переписки. Перед передачей скриншота уберите ненужные личные данные. Реальные переписки и скриншоты в этот публичный репозиторий не загружайте.

Для упражнения с браузером после самостоятельного входа в Instagram:

> Разбери два диалога, которые я укажу. Используй context.md и direct-prompt.md. Для каждого кратко опиши запрос собеседника и предложи готовый ответ. Пока ничего не отправляй.
