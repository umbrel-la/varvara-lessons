# Контекст блога Варвары Мининой

Материал для первого занятия по работе с Codex.

Основной файл: [context.md](context.md). Он содержит предварительное описание Варвары, направлений блога, аудитории и продуктов. Подтверждённые сведения, планы и гипотезы разделены; черновик нужно проверить с Варварой.

## Как добавить контекст в проект Codex

Откройте папку своего проекта в Codex и отправьте сообщение:

> Скачай файл https://raw.githubusercontent.com/umbrel-la/varvara-lessons/main/context.md в текущую папку проекта под именем context.md. Если такой файл уже существует, сначала покажи различия. Прочитай его, кратко расскажи, что ты понял обо мне и моём блоге, затем задай пять самых важных вопросов для уточнения аудитории и действующих продуктов. После моих ответов предложи изменения в файле.

Если скачивание недоступно, откройте context.md на GitHub, нажмите Raw и сохраните файл в папку проекта вручную.
